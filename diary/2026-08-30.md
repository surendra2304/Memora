## Bugs I Found & Fixed
- **UptimeRobot 405 Method Not Allowed**: Health check pings sent HTTP HEAD requests which FastAPI rejected.
  - *Fix*: Added explicit `methods=["GET", "HEAD"]` decorators to `/` and `/health` routes in `apps/api/main.py`.
- **Cloud SQLite Directory Missing**: SQLite database path initialization failed when parent directories did not exist.
  - *Fix*: Added automatic `os.makedirs(db_dir, exist_ok=True)` in `storage/relational/database.py`.
- **E2E Substring Match Sensitivity**: Dynamic synthetic summary wording variance caused test assertion mismatch.
