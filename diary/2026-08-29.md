## Bugs I Found & Fixed
- **Google API Key Regex Sizing Range**: Static length matching missed valid keys with variable character lengths.
  - *Fix*: Broadened regex pattern to `AIza[0-9A-Za-z-_]{30,40}` in `core/memory/pipeline/secret_scanner.py`.
- **Alembic SQLite Batch Alter Constraint Naming**: SQLite batch alter table mode required explicit foreign key constraint names.
  - *Fix*: Named constraint `'fk_agents_parent_agent_id'` in migration `9cf9d4184551_add_subagents_and_access_grants.py`.
- **Duplicate Memory Write Short-Circuiting**: Duplicate events previously attempted redundant persistence.
  - *Fix*: Added short-circuit handling in Step 6 returning existing record reference when `allow_duplicates=False`.

## Key Decisions & Architecture
- Enforced a predictable 10-step write pipeline to guarantee that no unvalidated, un-scanned, or un-audited memory enters storage.
- Blocked all unmasked secrets and credentials at Step 3 before normalization or persistent storage.
- Integrated dual-layer storage: relational ACID records in PostgreSQL paired with dense vector indexing in Qdrant.
- Implemented immutable audit logging capturing both successful writes and security policy violations.
- Bounded sub-agent memory visibility to designated project paths while shielding private parent memory stores.
