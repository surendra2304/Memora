## Bugs I Found & Fixed
- **Graph Traversal Edge Duplication Across Hops**: Repeated edge instances across multi-hop iterations artificially inflated edge counts.
  - *Fix*: Introduced `visited_edge_keys` tuple set in `GraphService.get_connected_memories` deduplicating edges during BFS expansion.
- **Historical Query Filter Propagation**: `include_superseded` flag was omitted when constructing query objects in REST endpoints.
  - *Fix*: Added `include_superseded` and `include_archived` fields to `MemoryQuery` schema and forwarded them to `MemoryService.query_memories`.
- **Alembic Relationship Index Creation**: SQLite batch migration required unique index generation for foreign keys.
  - *Fix*: Configured foreign key indices and applied migration `1218edca5327_add_memory_relationships`.

## Key Decisions & Architecture
- Adopted Reciprocal Rank Fusion (RRF) ($k=60$) to merge disparate semantic similarity scores and keyword BM25/lexical ranks without score calibration drift.
- Embedded local dense representations during write ingestion to guarantee zero-latency vector indexing.
- Simulated graph topology in PostgreSQL relational storage using indexed `MemoryRelationship` edges with hop-bounded traversal.
- Applied 5D policy authorization checks per candidate record before returning hybrid search results.
- Guaranteed that superseded memories remain accessible historically while keeping primary search spaces pruned.
