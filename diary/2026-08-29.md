## Bugs I Found & Fixed
- **Missing MemoryRecord Router Import**: `POST /v1/memories/{id}/share` failed due to missing `MemoryRecord` import in the router module.
  - *Fix*: Added `MemoryRecord` to imports in `apps/api/routers/v1_memories.py`.
- **Policy Engine Audit Action Typo**: Audit logs recorded generic action strings instead of `policy_allowed`/`policy_denied` expected by security auditors.
  - *Fix*: Standardized action field assignment in `PolicyEngine.log_audit_decision`.
- **Identity Grant Agent Resolution**: `IdentityService.grant_access` required UUID `agent_id` when callers provided `agent_name`.
  - *Fix*: Updated `IdentityService.grant_access` to accept `agent_name` or `agent_id` and resolve dynamically.

## Key Decisions & Architecture
- Isolated event bus communication to Redis Pub/Sub while maintaining an in-memory ring buffer for resilient local testing and zero-downtime boots.
- Enforced Prometheus-standard exposition formats alongside JSON to allow seamless scraping by Prometheus and Grafana dashboards.
- Enabled graceful degradation so that loss of vector indices does not bring down agent context generation; the system continues operating via relational FTS and graph edges.
- Maintained strict fail-closed policy checks across all retrieval and context bundle packing operations.
