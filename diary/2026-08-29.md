## Bugs I Found & Fixed
- **Graph Traversal Edge Duplication Across Hops**: Repeated edge instances across multi-hop iterations artificially inflated edge counts.
  - *Fix*: Introduced `visited_edge_keys` tuple set in `GraphService.get_connected_memories` deduplicating edges during BFS expansion.
- **Historical Query Filter Propagation**: `include_superseded` flag was omitted when constructing query objects in REST endpoints.
  - *Fix*: Added `include_superseded` and `include_archived` fields to `MemoryQuery` schema and forwarded them to `MemoryService.query_memories`.
- **Candidate State Supersession Transition**: `(CANDIDATE, SUPERSEDED)` transition was missing from the state machine set during contradiction subordination.
  - *Fix*: Added valid transition tuple in `core/lifecycle/state_machine.py`.

## Key Decisions & Architecture
- Enforced curated Context Bundles rather than raw database dumps to strictly guard agent LLM token windows.
- Integrated fail-closed policy checks during bundle creation, guaranteeing that unauthorized cross-agent data is never exposed.
- Formulated multi-factor reranking balancing semantic similarity, source confidence, time freshness, and importance.
- Bundled interconnected knowledge graph edges to provide topological relational context alongside textual memories.
- Formatted boundary items with structured truncation to optimize context packing density.
