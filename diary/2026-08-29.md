## Key Decisions & Architecture
- Enforced Rule 1 ("Private by default, shared by explicit promotion") as a non-negotiable security invariant.
- Enforced Rule 2 ("Project-shared namespaces require explicit project membership / grant") preventing ambient data sharing.
- Mandated that sub-agents inherit strictly bounded context without access to parent agent private memory.
- Standardized 5D context evaluation (Who, What, Where, Why, How long) on every policy evaluation.
- Stored all policy approval and denial events in immutable audit_logs table for compliance and security auditing.
